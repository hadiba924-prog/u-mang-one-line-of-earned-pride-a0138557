A single line of earned pride for the make.fun bounty
**"One Line of Earned Pride"** — one quiet scene, one small person, one
long effort finally landing.

The entry: after eleven ruined batches, a home baker pulls her first loaf
from the oven at dawn and taps the crust — and it sings back hollow, the
sound a good loaf makes. No trophy, no applause, no one congratulating
her. The pride is in the tap, and in the sound that answers it.

## Run it

Requires Node.js 22+ (stdlib only, no dependencies).

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(defaults to `/output`), with no trailing newline. The script exits
non-zero if the line is outside the 1–240 character gate.
